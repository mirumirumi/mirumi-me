# ブログ本文ブロックタイプ調査メモ（2026-07-04）

## 目的

レンタルサーバー側の WordPress/MySQL に入っている記事本文を走査して、現在使っている本文パターン・ブロックタイプを洗い出す。

例：通常テキスト、画像、キャプション付き画像、関連記事カード、テーブル、独自ボックスなど。

この調査は `futaribo` のアプリ設計・実装とは無関係。ユーザーが作業開始場所を間違えただけなので、このリポジトリ内の `.contexts/` は作業場所として使っているだけ。

## DB 接続の注意

- 単純に `mysql -e ...` を実行するとローカル socket を見に行って失敗する。
  - エラー例：`Can't connect to local MySQL server through socket '/var/lib/mysql/mysql.sock'`
- WordPress の DB 接続情報は SSH 先の `/home/c2485919/public_html/mirumi.in/wp-config.php` から読める。
- DB パスワードなどの秘密情報は出力しない。
- PHP を SSH の標準入力で渡し、`wp-config.php` から `DB_NAME` / `DB_USER` / `DB_PASSWORD` / `DB_HOST` / `$table_prefix` を読んで `mysql` に渡すのが扱いやすい。
- `MYSQL_PWD` はプロセス環境変数として渡せば、コマンドラインにパスワードを出さずに済む。
- PHP スクリプトを SSH コマンド文字列内に直接埋めると、ローカルシェル側のクォートで壊れやすい。`ssh conoha-wing 'php' <<'PHP' ... PHP` の形が安全。
- 日本語本文・タイトルを扱うときは MySQL CLI に `--default-character-set=utf8mb4` を付ける。未指定だと TSV 出力の日本語が `?` に化けた。
- 調査では書き込み系 SQL を実行しない。ここまで実行したのは `SELECT` のみ。

## 本文走査の対象

以下を対象にする。

```sql
SELECT ID, post_type, post_date, post_name, post_title, post_content
FROM wp_posts
WHERE post_type IN ('post', 'page')
  AND post_status = 'publish'
  AND post_password = ''
ORDER BY post_type, post_date, ID;
```

理由：

- ユーザー指定により非公開記事は除外する。
- `post_type = 'post' AND post_status = 'private'` は 42 件あるため除外。
- `post_type = 'post' AND post_status = 'publish'` は 468 件で、ユーザーの「記事数は 500 近く」という認識と合う。
- `post_type = 'page' AND post_status = 'publish'` は 9 件あり、固定ページも対象に追加した。
- 公開投稿 468 件にパスワード保護は 0 件。
- 公開投稿 468 件に本文空は 0 件。
- 公開固定ページ 9 件にパスワード保護は 0 件。
- 公開固定ページ 9 件のうち本文空は 1 件。

公開投稿 468 件の概要：

| target | count | min post_date | max post_date | empty content | password protected | min chars | avg chars | max chars |
|---|---:|---|---|---:|---:|---:|---:|---:|
| published posts | 468 | 2016-06-16 16:45:36 | 2026-06-25 19:23:23 | 0 | 0 | 415 | 11658 | 128472 |

固定ページ 9 件の概要：

| target | count | min post_date | max post_date | empty content | password protected | min chars | avg chars | max chars |
|---|---:|---|---|---:|---:|---:|---:|---:|
| published pages | 9 | 2016-06-13 01:54:28 | 2021-03-03 16:54:03 | 1 | 0 | 0 | 3635 | 7480 |

対象コンテンツリストは以下に保存済み。

## ブロックタイプ調査の前提

- Gutenberg は使っていない。DB 本文でも `<!-- wp:* -->` は 0 件。
- 実レンダリングは調べない。DB の `post_content` にある HTML / class / shortcode / 独自記法の種類を洗い出す。
- `[/best-pillows]` のような `[/slug]` は、閉じショートコードではなく関連記事カード用の独自記法として扱う。
- `[bps]`, `[V]`, `[Ctrl]`, `[username]` などは shortcode 風に見えるが、単位・キー表記・コード例・UI 文言なのでブロックタイプから除外する。
