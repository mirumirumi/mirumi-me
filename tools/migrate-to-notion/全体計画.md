## 背景

現在のブログは、WordPress を CMS / API サーバーとして使い、Nuxt 3 で SSG して S3 + CloudFront にデプロイしている。
フロントエンド自体には大きな不満はないが、WordPress 管理画面、PHP、レンタルサーバー、DB 管理、更新フローなどへの細かなストレスが蓄積している。

また、ブログ更新頻度が下がっており、今後もブログを続けるために「気軽に書ける環境」を作ることが重要になっている。
技術的な脱 WordPress だけでなく、執筆体験そのものを軽くすることが今回の主目的。

## 課題

### 1. 執筆体験が重い

- 現在は VS Code で書いて WordPress のクラシックエディタに貼り付けるような運用になっている
- WordPress 自体には慣れているが、管理画面を開くこと、余計な UI が目に入ること、公開後の反映待ちなどが心理的な摩擦になっている
- 目指す体験は、ブラウザのタブ 1 枚で書けて、余計なものが見えず、すぐ公開・確認できること

### 2. WordPress / レンタルサーバー依存

- WordPress は CMS としては高機能だが、API サーバーとして残り続けていることが負担
- なにより ConoHa WING がゴミ。レンタルサーバーは本当にゴミ。詐欺と言っても差し支えない
- ただし既存記事は 500 本近くあり、本文は WordPress DB 内の HTML
  - コンテンツ資産として重要なので、移行は慎重に行う必要がある

### 5. 公開反映速度

- 現在も全ビルドではなく、1 記事だけ generate できる GitHub Actions があるが、それでも反映に数分かかる。
- 一時は Nuxt SSR + Cloudflare Workers + D1 も検討したが、現時点では SSR 化は保留
  - SSR 化の保留については自信を持っている
    - https://app.asana.com/1/1209029477658805/task/1216031837489931/comment/1216174363465104?focus=true
